# Goldie Listing Factory approved visual baseline

This file is the frozen visual contract for the pink, lilac, and peach Goldie Listing Factory build. Functional changes must not restyle, reposition, replace, or reinterpret these elements unless Brittany explicitly approves that exact visual change.

## Frozen layout

- The sidebar keeps the approved width, spacing, full-width navigation rows, logo lockup, and translucent selected state.
- The Usage card is bottom-anchored in the sidebar.
- `Powered by Goldie AI` and `© 2026 Be A Wolf Biz` sit directly below the Usage card.
- The main workflow keeps the approved glass card, background composition, spacing, typography, and plum buttons.
- The nine-step bubble tracker and its connecting line remain at the top.
- Printify and Etsy connection controls use the same button dimensions, radius, typography, and alignment.
- The chain-link icon stays still. Only its thin gradient border may animate.
- Primary workflow buttons say `Next step` and use a compact, centered arrow gap.

## Frozen connection-step details

- Printify and Etsy are both required before moving to Step 2.
- `How to get your Printify token` belongs inside the Printify section, directly below the Printify connection controls.
- The token-help link is visually secondary, readable, and smaller than the connection buttons.
- Printify instructions expand inside the Printify section.
- Etsy is a separate matching connection row below the complete Printify section.

## Change-control rule

Before deployment, compare both the live app and `public/goldie-real.html` against this file. A functionality change may not alter the frozen visual rules. If a regression occurs, restore this checkpoint before making any further changes.
